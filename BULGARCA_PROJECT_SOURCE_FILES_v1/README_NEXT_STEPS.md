# BULGARCA — İlk Kurulum Sonraki Adımlar

1. Bu klasördeki `.md` dosyalarını ana repo içinde `docs/` klasörüne ekle.
2. `CODEX_PROMPT_001_STATIC_MVP.md` dosyasını Codex/Antigravity’ye ver.
3. Codex/Antigravity’nin oluşturduğu uygulamayı `mustafasacar50/bulgarca` reposuna push et.
4. Ayrı `mustafasacar50/bulgarca-user-data` reposunda şu dosyaları oluştur:
   - `users/mustafa/progress.json`
   - `users/mustafa/difficult-words.json`
   - `users/mustafa/known-words.json`
   - `users/mustafa/review-queue.json`
   - `users/mustafa/lesson-state.json`
5. GitHub tokeni uygulama arayüzünden manuel girilecek. Token hiçbir dosyaya yazılmayacak.
6. Uygulama iskeleti çalışınca mevcut PDF’lerden ilk import paketi üretilecek.
